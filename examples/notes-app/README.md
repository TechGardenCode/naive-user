# Example: notes-app

A worked, generic config for a fictional note-taking web app. It shows what a real
`naive-user.config.json` looks like once filled in. Copy `naive-user.config.json` into your
own app repo's root, swap in your real `baseUrl`, `startCommand`, and auth steps, and run
`/naive-test`.

`coverageNotes` here is a fuller-than-usual example of the hints you can leave: a first-time
user's tour of the app surface (sidebar, theme toggle, capture box, search, entries list,
entry detail, empty and loading states). They are hints, not a script. The agent still surveys
the live app and may find gaps the notes do not mention.
