# Example: iris

A worked per-app config for the `iris` product — the original app this skill was built
against. Copy `naive-user.config.json` into your iris repo root (fill in the real
`baseUrl` port) and run `/naive-test iris`.

`coverageNotes` here is a fuller-than-usual example of the kind of hints you can leave: a
first-time user's tour of iris's surface (sidebar, theme toggle, capture box, search,
entries list, entry detail, empty/loading states). They're hints, not a script — the skill
still surveys the live app and may find gaps the notes don't mention.
